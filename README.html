烘焙方式

原场景 90 个程序化材质无法直接进 WebGL，按集合拆成 8 组：建筑 / 家具 / 女仆 / 窗外近景 用 4096²，软装（床品 / 装饰 / 绿植 / 窗饰）用 2048²；城市远景用平面颜色；电视与画框保留原始高清图。GLB 22 MB，实时几何约 35 万三角面。
